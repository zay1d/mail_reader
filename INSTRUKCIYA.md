# Почта ресепшн — установка, подключение, наладка

Программа читает ящик ресепшн в Outlook, показывает письма, которые ждут ответа, отправляет
автоответ, пересылает письма в отделы, поднимает тревогу при угрозах и в конце смены
отправляет отчёт руководителю. Работает на одном ПК ресепшн, сервер не нужен.

## 0. Где взять архив
Архивы собираются автоматически на GitHub: репозиторий → вкладка **Actions** → последний зелёный запуск «build» →
внизу **Artifacts** → `reception-mail_v…` (внутри `reception-mail_install_v….zip` для новой установки и
`reception-mail_update_v….zip` для обновления).

### Что нового в 1.35
- Сортировка писем через ИИ (раздел 5а) — по желанию; без ключа всё работает как раньше.
- Угрозы: ловятся узбекские слова с апострофом ʻ ‘, угрозы с переносом строки, «всех зарежу», «взлетит на воздух»;
  слово рядом с угрозой («квартире») больше не гасит тревогу.
- Автоответ и пересылка в отдел повторяются, если Outlook был занят; не уходят ответам чужих автоответчиков.
- Карточки не снимаются как «удалено из Outlook», если Outlook прочитался не полностью.
- Смены до «00:00» и ночные смены: срок ответа считается правильно.
- Telegram: если тревога не дошла до кого-то из получателей — повтор именно ему, причина в журнале.
- Адреса отчёта и СБ можно писать через запятую.
- Испорченный config.json восстанавливается из вчерашней копии автоматически.
- Команды программе принимаются только с её экрана (сайт из письма не может снять тревогу).

## 1. Что должно быть на ПК ресепшн
- Windows 10/11, интернет.
- **Классический Outlook** (не «новый Outlook» с переключателем в правом верхнем углу),
  в нём открыт ящик **contact@tcmall.uz**. Outlook запущен всё рабочее время.
- ПК включён в рабочие часы. Если на ночь выключают — утром программа сама дочитает почту.

## 2. Установка в пустую папку (5 минут)
1. Если программа уже стоит: Настройки → PIN → «Остановить программу»; в Диспетчере задач не должно
   остаться ReceptionMail.exe. Старую папку удалить.
2. Распаковать `reception-mail_install.zip` в пустую папку `C:\ReceptionMail` — в ней сразу ReceptionMail.exe.
3. Открыть классический Outlook с ящиком contact@tcmall.uz, запустить `ReceptionMail.exe`
   («Windows защитил ваш компьютер» → «Подробнее» → «Выполнить в любом случае»).
4. Программа сразу работает с Outlook, ставит ярлык на рабочий стол, автозапуск и сторожа.
   Письма учитываются с минуты первого запуска — старые не попадут в очередь и не получат автоответ.

## 2а. Обновление (настройки и история сохраняются)
1. Настройки → PIN → «Остановить программу»; в Диспетчере задач не должно остаться ReceptionMail.exe.
2. Распаковать `reception-mail_update_v….zip` в ту же папку `C:\ReceptionMail` → «Заменить файлы».
   В архиве обновления нет config.json и data — настройки, PIN, сотрудники и база писем не меняются.
3. Запустить ярлык «Почта ресепшн», в браузере Ctrl+F5. В Настройках вверху — новая версия.

## 3. Настройка (5 минут) — Настройки, PIN 0000
1. «Проверить подключение к Outlook»: «Подключение: OK (учётная запись contact@tcmall.uz)», внизу
   «Входящие — … ошибок чтения 0».
2. Почта руководителя ресепшн (раздел «Смены и отчёт»), телефон СБ (раздел «Угрозы»).
3. PIN администратора: сменить 0000 на свой. «Сохранить настройки».

Уже внесено: ящик contact@tcmall.uz, 12 сотрудников, телефон ресепшн, пересылка «Аренда» →
k.sabitova@tcmall.uz, «Маркетинг» → k.saipova@tcmall.uz, текст автоответа на трёх языках.
При первой отправке Outlook может спросить «Программа пытается отправить сообщение» — «Разрешить».

## 4. Проверка (5 минут)
1. С личной почты отправить письмо на contact@tcmall.uz. В течение минуты на экране
   появится карточка, на личную почту придёт автоответ.
2. «Ответить в Outlook» → откроется сам Outlook с выделенным письмом → ответить как обычно. Через несколько секунд карточка исчезнет, счётчик
   «Отвечено» вырастет.
3. «Закрыть смену и отправить отчёт». Руководителю придёт отчёт. При первой отправке
   Outlook может спросить разрешение на отправку от программы — нажать «Разрешить».

## 5. Telegram для тревоги (по желанию, 10 минут)
1. В Telegram написать @BotFather → `/newbot` → получить токен.
2. Настройки → Угрозы → вставить токен → «Сохранить настройки».
3. Добавить бота в группу службы безопасности и написать в группе `/start@имя_бота` (без этого бот
   группу не увидит). Личные получатели пишут боту `/start`.
4. «Показать, кто написал боту» → нажать на группу (ID начинается с -100) и нужных людей → «Сохранить» →
   «Отправить проверочное сообщение» → сообщение должно прийти в группу.
5. Если «Ошибка: … timed out / connection» — сеть ПК ресепшн не пускает в Telegram: попросить IT открыть
   доступ к api.telegram.org (порт 443).

## 5а. Сортировка писем через ИИ (по желанию, 10 минут)
Без ИИ программа сортирует письма по ключевым словам. С ИИ (Claude) она понимает смысл письма: точнее выбирает
направление и приоритет, правильнее определяет язык автоответа и пишет на карточке одну строку «о чём письмо».
1. Зайти на console.anthropic.com → зарегистрировать организацию → Billing: пополнить баланс (хватит $10–20 в месяц:
   Opus 5.5 — примерно 1–2 цента за письмо, Haiku 5.5 — в 20–40 раз дешевле).
2. API Keys → Create Key → скопировать ключ `sk-ant-…`.
3. Настройки → «Сортировка писем через ИИ» → вставить ключ, отметить галочку → «Сохранить настройки» →
   «Проверить ИИ». Должно появиться «✓ ИИ работает … направление «rent»».
4. Если «нет связи с api.anthropic.com» — попросить IT открыть доступ к api.anthropic.com (порт 443).
- Если ИИ недоступен (нет интернета, кончился баланс), письма сортируются по ключевым словам, как раньше;
  причина — в журнале и в Настройках.
- Тревогу по угрозам поднимают ключевые слова, как раньше. ИИ может только добавить жёлтый экран «проверьте письмо».
- Направление уходит не туда → Настройки → Направления → «Описание для ИИ»: дописать, какие письма туда относятся.
- Текст писем отправляется в сервис Anthropic для сортировки.

## 6. Наладка в первые недели
- **Письмо попало не в то направление** → Настройки → Направления → дописать слова (с ИИ — уточнить «Описание для ИИ»).
- **Ложная тревога** → Настройки → Угрозы → «Исключения», добавить фразу.
- **Угрозу пропустило** → добавить слово в «Явная угроза» или «Возможная угроза».
- **Рассылка висит в очереди** → «Что не считать входящими», добавить адрес отправителя.
- **Письма от коллег @tcmall.uz не должны считаться** → туда же добавить `@tcmall.uz`.
- Пересылка в другие отделы → Настройки → Направления → поле «Пересылать на адрес».
- **Письмо не ушло в маркетинг/аренду** → дописать слово в направление; надёжнее всего указать
  отдел в теме: «Для маркетинга», «В отдел аренды».
- Состав сотрудников → Настройки → Смены и отчёт.

## 7. Как работает сотрудник
- Начало смены: «Открыть смену» → отметить себя галочкой → «Подтвердить».
- Карточка = письмо без ответа. Слева — сколько осталось до срока: зелёный, жёлтый,
  оранжевый, красный = просрочено. «Срочно» — 15 минут, обычные — час, «Низкий» — 4 часа.
- «Ответить в Outlook» → разворачивается главное окно Outlook, письмо уже выделено → ответить
  как обычно → карточка уходит сама. Автоответ программы ответом не считается.
- Автоответ уходит на каждое новое письмо (и на пересланные в отделы). Повторное письмо
  с той же темой от того же адреса автоответ не получает.
- Письма коллег с @tcmall.uz автоответ не получают и в отделы не пересылаются (остаются в списке).
  Поэтому проверять автоответ нужно с личной почты, не с рабочей.
- Версия программы видна в Настройках (вверху) и при наведении на статус в шапке экрана.
- Пилюли сверху: сколько писем по направлению за смену; красный кружок — ждут, зелёный — обработано.
  Нажатие на пилюлю — под ней список этих писем и что с каждым (ждёт / отвечено / переслано); «Скрыть» — убрать.
- **Заявка с сайта** (от support@o-d.one, на карточке «ответ клиенту: адрес»): отвечать ТОЛЬКО кнопкой
  «Ответить в Outlook» — откроется ответ, где в «Кому» уже адрес клиента. «Ответить» в самом Outlook
  уйдёт на наш же ящик contact@ (так настроена форма сайта) — клиент не получит. Автоответ уходит клиенту.
- **Красная пометка «Ответ ушёл на …, а не клиенту»** — ответ на заявку ушёл на contact@ или коллегам, клиент его
  не получил, письмо осталось в очереди. Ответить ещё раз через «Ответить в Outlook».
- **Каждое письмо из Outlook — на экране**: карточка (ждёт ответа) или внизу — «Отвечено за смену»,
  «Переслано в отделы», «Сняты без ответа» (угроза после «Я сообщил», удалено в Outlook),
  «Не попали в очередь» (рассылки, автописьма, приглашения на встречу, отчёты о недоставке — с причиной).
  Письмо человека в «Не попали в очередь» → «Нужен ответ» (встанет в очередь без автоответа).
- В шапке «сбоев чтения Outlook: N» — часть писем может не показываться: Настройки → «Проверить подключение».
- Письмо с пометкой **«из «Нежелательной почты»»** — пришло в спам. Настоящее → в Outlook правой кнопкой
  «Нежелательная» → «Не нежелательное» (уйдут автоответ и пересылка); спам → удалить в Outlook, карточка
  исчезнет через 2 минуты. Рассылки из спама не показываются.
- **Красный экран** — явная угроза: позвонить в СБ, затем «Я сообщил в службу безопасности».
  Экран закреплён поверх всех программ и возвращается, если его свернуть или закрыть, — до нажатия
  «Я сообщил». «Открыть это письмо в Outlook» освобождает экран на 90 секунд, чтобы прочитать письмо.
- **Жёлтый экран** — возможная угроза: открыть письмо, затем «Это угроза» или «Угрозы нет».
  После «Угрозы нет» письмо обрабатывается как обычное: уходит автоответ, при нужном направлении — пересылка в отдел.
- Конец смены: зелёная кнопка «Закрыть смену и отправить отчёт». Смену открывают и закрывают
  только вручную. Если прошлая смена забыла закрыть — следующая сначала закрывает её.
- Отчёт смены = всё от кнопки «Открыть смену» до кнопки «Закрыть смену», часы не участвуют.
  Письма, пришедшие между сменами (ночью), считаются следующей смене.
- Ответил — карточка уходит через 2–5 секунд после отправки (программа каждые 2 секунды смотрит,
  не появилось ли новое в «Отправленных»). Полный опрос почты — Настройки → «Опрос почты, секунд» (от 5).

## 8. Если что-то не так
- **Закрыли окно, а уведомления идут** → закрытие вкладки браузера программу не останавливает:
  она работает в фоне (так задумано, экран открывается ярлыком снова). Остановить полностью:
  Настройки → PIN → «Остановить программу» (сторож при этом снимается).
- **Статус красный «Нет связи с Outlook»** → открыть Outlook; проверить, что он классический.
- **Экран не открывается** → запустить ярлык ещё раз. Если программа не стартует — причина в
  `data/error.log` и в окне с сообщением (например, занят порт 8791).
- **Настройки слетели / всё в демо-режиме** → файл `config.json` был повреждён и переименован в
  `config.json.broken`; вернуть вчерашнюю копию из `data/backup/config-ДАТА.json` (копии базы и
  настроек делаются раз в день, хранятся 14 дней).
- **Письмо удалили из Outlook** → через 2 минуты карточка снимается с очереди сама (в отчёте —
  «удалено из Outlook сотрудником»).
- **Программу закрыли через Диспетчер задач** → сторож в Планировщике Windows («ReceptionMail
  Watchdog») запускает её заново в течение 5 минут. Забыли PIN → открыть `config.json`, поле
  `admin_pin`.
- **«Слишком много неверных PIN»** → 5 ошибок подряд закрывают вход в Настройки на 5 минут (защита от подбора).
- **Отчёт смены**: «Отвечено» — все ответы за смену (в т.ч. на письма прошлых смен), «Без ответа» — всё, что висит
  в очереди на момент закрытия. Цифры совпадают с экраном.
- **«Параметр задан неверно» / «ящик не найден»** → очистить поле «Адрес ящика ресепшн
  в Outlook», сохранить, нажать «Проверить подключение к Outlook».
- **Письма не появляются** → «Проверить подключение к Outlook» и дата «Учитывать письма начиная с».
- Журнал программы: Настройки → внизу «Показать журнал программы» (сохраняется после перезапуска,
  файл `data/journal.log`).
- Данные: `config.json` (настройки), `data/mail.db` (журнал писем), `reports/` (отчёты).
  Перенос на другой ПК = копирование всей папки.
